# FuzzyFi presentation

Slides for **FuzzyFi**, a Soft Computing mini project at BMS College of Engineering by Shrilaxmi Heralagi and Sneha Uday.

FuzzyFi places two Wi-Fi routers on a hostel floor. Particle Swarm Optimization searches for the positions, and fuzzy logic rates the signal at every spot.

Live at https://shree-hlg.tech

This site only presents the project. The heat maps and chart are drawn from results saved from the Python code (`data.js`); nothing is calculated in the browser.

Open `index.html` in a browser. Use the arrow keys or the Next and Back buttons to move between slides, and press F for full screen.
